## 1. 整体架构说明

- **前端跨平台层（`uni-app` Vue 3）**：一套代码同时编译为微信小程序原生 WXML、iOS/Android App、Web PWA，以及嵌在 **Tauri v2** 中的桌面客户端界面。
- **离线优先存储层（`utils/store.js`）**：按题库 ID 自动分片存储到本地缓存（彻底避开微信小程序单 Key 1MB 上限），没网也能毫秒级流畅刷题。
- **云端同步层（`uniCloud` 云函数 `quiz-sync`）**：同时支持 **原生 SDK 直连**（小程序/App 免配置）与 **HTTP URL 化直连**（供电脑桌面端与 GitHub Pages 网页端跨平台调用）。

## 2. 第一步：开通 uniCloud 免备案云同步（全端互通核心）

> 💡 如果暂时不开通云端，所有平台依然可以 **100% 正常本地离线导题和刷题**；开通后即可多设备同步进度。

1. 下载并安装官方免费开发工具 **[HBuilderX](https://www.dcloud.io/hbuilderx.html)**（选择正式版即可，无需在电脑安装 Node.js）。
2. 打开 HBuilderX，点击左上角 **「文件 → 导入 → 从本地目录导入」**，选择本项目根目录。
3. 打开 `manifest.json` → **基础配置**，点击 **「重新获取」** 生成属于你自己的 DCloud AppID（若提示登录 DCloud 账号，免费注册登录即可）。
4. 在左侧项目树右键点击 **`uniCloud-aliyun`** 文件夹 → 选择 **「关联云服务空间或项目」** → 点击 **「新建服务空间」**（支付宝云/阿里云均有免费或极低门槛开发版空间，国内访问极快且免域名备案）并关联。
5. **一键上传数据表与云函数**：
   - 展开 `uniCloud-aliyun/database`，右键点击 `database` 目录 → **「上传所有 DB Schema」**（自动创建 `qs_users`、`qs_tokens`、`qs_banks`、`qs_records`、`qs_exams` 五张安全表）。
   - 展开 `uniCloud-aliyun/cloudfunctions/quiz-sync`，右键点击 **`quiz-sync`** → **「上传部署」**。
6. **开启「云函数 URL 化」（让电脑客户端与 GitHub Pages 网页也能同步！）**：
   - 右键 `uniCloud-aliyun` → **「打开 uniCloud Web 控制台」**。
   - 进入 **云函数/云对象 → `quiz-sync` → 详情 → 云函数 URL 化**，点击编辑，设置路径为 `/quiz-sync` 并保存。
   - 复制生成的 HTTPS 地址（形如 `https://env-xxxx.../quiz-sync`），粘贴到网页版或电脑客户端「云同步 → 云端服务连接设置」中保存（或者直接填入代码 `utils/cloud.js` 的 `DEFAULT_CLOUD_HTTP_URL` 常量再推送到 GitHub，以后所有端就永久免填了！）。

## 3. 第二步：运行与发布「微信小程序」

### 3.1 准备工作
1. 前往 [微信公众平台](https://mp.weixin.qq.com/) 免费注册一个小程序账号，在「开发管理 → 开发设置」获取 **AppID** 和 **AppSecret**。
2. 安装 **[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)**，并在其顶部菜单打开 **「设置 → 安全设置 → 开启服务端口」**。

### 3.2 配置微信一键登录（可选，不配也可直接用账号密码登录）
1. 在 `uniCloud-aliyun/cloudfunctions/quiz-sync/` 目录下，将 `config.json` 复制一份重命名为 **`config.local.json`**（该文件已被 `.gitignore` 忽略，绝不会泄露到公开 GitHub）：
   ```json
   {
     "wxAppId": "你的微信小程序AppID",
     "wxAppSecret": "你的微信小程序AppSecret"
   }
   ```
2. 右键 `quiz-sync` 重新点击 **「上传部署」**。

### 3.3 运行与上传审核
1. 在 HBuilderX 打开 `manifest.json` → **微信小程序配置**，填入你的 **微信小程序 AppID**。
2. 点击顶部菜单 **「运行 → 运行到小程序模拟器 → 微信开发者工具」**，即可在模拟器或手机扫码真机预览！
   - 在小程序里上传题库超简单：先把 `.xlsx` / `.csv` / `.docx` / `.txt` 发到微信 **「文件传输助手」**，在小程序「导入」页点击上传框即可直接从聊天记录选中解析！
3. 正式上线前：在微信公众平台「开发设置 → 服务器域名」中，将 `uniCloud` 分配的域名加入 `request合法域名`（`uniCloud` 官方域名本身已完成国内备案，直接填入即可），然后在微信开发者工具右上角点 **「上传」** 提交审核。

## 4. 第三步：云打包「Android (.apk) 与 iOS (.ipa) 手机 App」

无需在自己电脑安装庞大的 Android Studio！

1. 在 HBuilderX 打开 `manifest.json` → **App 图标配置**，选择项目里的 `static/logo.png` 点击 **「自动生成所有图标并替换」**。
2. 点击顶部菜单 **「发行 → 原生 App-云打包」**：
   - **Android 打包**：勾选 **Android (apk包)**，证书选择 **「使用云端证书」**（DCloud 免费自动生成），点击 **「打包」**。等待几分钟后控制台会直接给出 `.apk` 下载链接，发到安卓手机即可直接安装！
   - **iOS 打包**：如有苹果开发者证书（`.p12` + `.mobileprovision`），勾选 **iOS (ipa包)** 填入证书即可云打包；若仅装在自己 iPhone 上使用，也可选择「发行 → 原生 App-本地打包 → 生成本地打包 App 资源」，用 Mac 上的 Xcode 免费个人 Apple ID 签名安装到手机。

## 5. 第四步：云端自动编译「Windows / macOS / Linux 电脑客户端」

本项目已内置 **Tauri v2**（比 Electron 体积小 90%，安装包仅约 5MB）以及 **GitHub Actions 三端矩阵流水线**，你无需买 Windows 电脑、也无需在本机装 Rust：

1. 打开你的 GitHub 仓库：`https://github.com/AtomBoyC/exam-sprint-quiz`
2. 点击顶部 **Actions** 标签页 → 左侧选择 **「Build Desktop Apps (macOS / Windows / Linux)」**。
3. 点击右侧 **「Run workflow」** 按钮确认启动。
4. 等待约 8～12 分钟云端编译完成后，点进该次任务底部的 **Artifacts** 区域即可直接下载三端原生安装包：
   - **`ExamSprint-macOS-Universal`**：苹果芯片 M1/M2/M3/M4 与 Intel 通用的 `.dmg` 安装包
   - **`ExamSprint-Windows-x64`**：Windows 10/11 `.exe` / `.msi` 安装程序
   - **`ExamSprint-Linux-x64`**：Ubuntu / Debian `.AppImage` 与 `.deb` 安装包

> 💡 如果在 macOS 打开未公证的开源 `.app` 提示“无法验证开发者”，在「系统设置 → 隐私与安全性」底部点击「仍要打开」，或在终端执行 `xattr -cr /Applications/ExamSprintQuiz.app` 即可正常打开。

## 6. 多设备同步逻辑与账号绑定说明

### 6.1 微信登录与电脑/网页端如何互通？
- 如果你先在微信小程序点了 **「💬 微信一键快捷登录」**：在「云同步」页会看到 **「🔗 绑定跨端通行证账号密码」** 卡片，设置一个账号名和密码后，在 Windows / Mac / 网页 / Android / iOS 输入该账号密码登录，就能共享同一个题库与进度！
- 反之，如果你先用账号密码注册登录，在微信小程序登录后点击 **「绑定当前微信号」**，下次就能直接一键登录。

### 6.2 多端同时离线刷题会冲突吗？
不会！系统采用 **题目级无冲突合并算法（`utils/merge.js`）**：
- 每道题独立记录 `updatedAt` 时间戳；A 设备刷第 1～20 题、B 设备离线刷第 21～40 题，同步后 1～40 题进度完整合入。
- 同一道题在两端都做过时：对错累计次数取幂等最大值（防重复累加），掌握/错题状态以最新作答时间为准，且任一端写下的**非空助记笔记**均会自动保留不丢失。

## 7. 全平台题库导入与刷题指南

- **支持文件格式**：`.xlsx` (Excel)、`.csv` / `.tsv`（自动识别 UTF-8 与 GBK）、`.docx` (Word 表格与段落)、`.txt` / `.md`、`.json`。
- **PDF 题库导入技巧**：打开 PDF 全选复制文字 → 粘贴到「导入」页的 **智能粘贴框** → 点击「智能识别题目」。
- **桌面端/网页端快捷键**（沉浸刷题页自动生效）：
  - `1`–`6` 或 `A`–`F`：选答案（判断题 `1` 对 / `2` 错）
  - `Enter` / `Space`：提交多选或切换下一题
  - `←` / `→`：上一题 / 下一题（手机端支持**左右滑动切题**）
  - `S`：收藏本题 ｜ `K`：斩杀本题 ｜ `R`：背题遮挡切换

## 8. 常见问题排查（FAQ）

**Q1：网页版或电脑端点击登录提示“尚未关联 uniCloud 服务空间或填写云函数 URL”？**  
A：请按本文档 **第 2 节第 6 步**，将 `quiz-sync` 云函数开启 URL 化后，把 HTTPS 地址填到「云同步 → 云端服务连接设置」并保存即可。

**Q2：我想继续用最早那个双击即开的单文件 HTML 版在哪里？**  
A：已完整保留在仓库的 `standalone-html/index.html` 中，在线版也可以直接访问 `https://atomboyc.github.io/exam-sprint-quiz/lite/`！
