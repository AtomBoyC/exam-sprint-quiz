# ⚡ 极速刷题宝 (ExamSprint Quiz)

一款**零依赖、纯前端、100% 本地离线运行**的智能题库刷题 Web 应用。无需安装 Node.js / Python / 数据库，下载后直接双击 [`index.html`](./index.html) 或托管到 **GitHub Pages**，即可在电脑和手机浏览器中随时上传自己的题库高效刷题。

> 📘 **完整图文级使用与部署手册**：请查看 **[操作文档 (`docs/操作文档.md`)](./docs/操作文档.md)**

---

## ✨ 核心特性

- **🔒 纯本地离线 · 隐私零泄露**：所有题库解析与刷题记录均保存在浏览器本地（IndexedDB + localStorage），不会上传到任何第三方服务器。
- **📂 全格式智能解析（无第三方库依赖）**：
  - 原生离线解析 **Excel (`.xlsx`)**、**CSV / TSV**（自动兼容 UTF-8 与中文 Excel 的 GBK/GB18030 编码，绝不乱码）、**Word (`.docx` 表格与段落)**、**TXT / Markdown**、**JSON**。
  - **智能粘贴模式**：支持从 PDF / Word / 网页直接全选复制粘贴，自动识别纯文本题目、无表头 CSV、行内选项（`A. xx B. xx`）、题干括号内嵌答案（`（A）`/`（√）`）以及文末「参考答案汇总」（`1.A 2.BC` 或 `1-5: ABCDA`）。
  - **可视化列映射**：表格导入前支持多工作表（Sheet）切换、表头开关与实时列映射微调。
- **🎯 6 大高效刷题模式**：
  1. **📖 顺序刷题**：按题库原序练习，即时批改与解析，支持单选/判断答对自动跳下一题。
  2. **🔀 随机乱序刷题**：打乱题序，可叠加**「选项乱序」**，杜绝只背字母位置不背知识点。
  3. **⚔️ 斩杀冲刺模式**：只刷尚未掌握的题，连对达标自动“斩杀”清零，考前突击超解压。
  4. **⚡ 极速背题模式**：直接高亮答案与解析，支持一键「遮挡答案」（快捷键 `R`）主动回忆。
  5. **🎯 错题本攻坚**：按历史错题频次自动置顶重刷，支持一键导出 **「考前错题速记打印单 (.html)」** 打印或存 PDF。
  6. **⏱️ 全真模拟考试**：自定义抽题数量与倒计时，交卷后自动评分、分题型正确率统计并一键复盘错题。
- **📱 全端友好 + 极速体验**：
  - 支持 **单选、多选、判断、填空、简答（自评）** 5 大题型，按题型/章节筛选。
  - 每题支持 **收藏**、**个人助记笔记**、**在线编辑修正**、**断点续刷**。
  - 支持 **深夜护眼暗色模式**、字号调节、**桌面全键盘快捷键**、**手机端左右滑动切题 + 抽屉式答题卡**。

## 🚀 快速开始

### 方式一：本地直接使用（最简单）
1. 下载或克隆本仓库到本地：
   ```bash
   git clone https://github.com/AtomBoyC/exam-sprint-quiz.git
   ```
2. 直接双击打开文件夹中的 **`index.html`**（推荐使用 Chrome / Safari / Edge）。
3. 点击 **「📤 上传我的题库」** 导入你的题目文件，或点击 **「✨ 先加载示例题库体验」** 立即试用。

### 方式二：GitHub Pages 手机/电脑在线访问
直接访问在线地址：**[https://AtomBoyC.github.io/exam-sprint-quiz/](https://AtomBoyC.github.io/exam-sprint-quiz/)**

> 手机和电脑均可直接打开使用，导入的题库和答题进度依然只保存在你各自设备的浏览器本地。如需在自己 Fork 的仓库开启，前往仓库 **Settings → Pages → Branch: `main` / `(root)` → Save** 即可。

## ⌨️ 常用快捷键（刷题界面）

| 快捷键 | 功能 |
|---|---|
| `1` – `6` 或 `A` – `F` | 快速选择对应选项（判断题：`1` 正确 / `2` 错误） |
| `Enter` / `Space` | 提交多选/填空，或跳转下一题 |
| `←` / `→` | 上一题 / 下一题 |
| `S` | 收藏 / 取消收藏本题 |
| `K` | 斩杀 / 取消已掌握标记 |
| `R` | 背题模式下切换遮挡/显示答案 |
| `D` | 切换浅色 / 深夜护眼暗色模式 |
