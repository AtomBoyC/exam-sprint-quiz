## 1. 三种运行方式（网页 / 本地免装 / 原生电脑客户端）

1. **在线网页版（推荐跨电脑随时打开）**
   - 直接访问：`https://atomboyc.github.io/exam-sprint-quiz/`
   - 在 Chrome / Edge 地址栏右侧点击 **「安装极速刷题宝」** 图标，即可作为独立桌面窗口运行，支持断网离线使用。
2. **本地双击免安装运行**
   - 下载仓库后无需安装任何编程环境，直接用浏览器双击打开根目录的 `index.html` 即可运行。
   - 若本机存有私密预置题库 `js/builtin-bank.js`（已被 `.gitignore` 忽略保护），首次打开将自动载入。
3. **Tauri 原生桌面客户端（Windows `.exe` / macOS `.dmg` / Linux `.AppImage`）**
   - 见本文档第 6 节，通过 GitHub Actions 云端一键生成，安装包仅 ~5MB，原生系统窗口体验。

## 2. 题库导入与格式规范（全格式离线解析）

进入左侧栏 **「智能导入题库」**：

- **Excel (`.xlsx`) 与 CSV / TSV**：
  - 自动跳过顶部横幅标题行识别表头（`题型 / 题目 / 选项A~H / 合并选项 / 答案 / 解析 / 章节`）。
  - 即使是**无表头、含多列空白**的导出 CSV，也会智能推断题干、选项、答案与章节；也可在预览面板手动切换 Sheet 或下拉微调列映射。
  - 自动识别 UTF-8 与中文 Windows/Excel 默认的 **GBK / GB18030** 编码，杜绝乱码。
- **Word (`.docx`)**：同时支持表格排版与普通段落排版。
- **TXT / Markdown / 智能粘贴（PDF 题库推荐）**：
  - 打开 PDF 全选复制文字粘贴到右侧框，自动识别单选、多选、判断、填空、简答，支持行内选项（`A. xx B. xx`）、题干括号内嵌答案（如 `（A）` 自动挖空防剧透）以及文末「参考答案汇总」（`1.A 2.BC` 或 `1-5: ABCDA`）。
- **导入自动去重**：默认勾选「导入时自动合并清理重复题目」，相同题干重复出现时会自动合并且保留更完整的解析。

## 3. 工作台、精准范围选刷与 7 大刷题模式

### 3.1 精准范围与防背位置控制
- **题号区间选刷**：例如面对 400 题大题库，可填写起始题号 `1` 至 `100`，分阶段稳步突破。
- **题型与章节筛选**：可单独筛出「仅多选题」或某一薄弱章节集中训练。
- **选项乱序**：每次出题动态重排 A/B/C/D 内容并自动映射标准答案，防止形成“第5题选B”的假性位置记忆。

### 3.2 7 大模式详解
1. **📖 顺序精刷**：按原题序推进，即时批改并自动保存断点，下次打开可一键续刷。
2. **⚔️ 斩杀冲刺**：只出尚未掌握的题；连对达标（可在设置选连对 1/2/3 次）即标记为「已斩杀」，实时显示待斩余量。
3. **🧠 艾宾浩斯记忆复习**：每次作答后系统按 **SM-2 算法** 计算下次最佳复习时间（答错 10 分钟后复现，答对按 1天 → 3天 → 7天…递增），点击即可把当前到期的题目一网打尽。
4. **🔀 随机乱序**：全随机抽题检验真实掌握水平。
5. **⚡ 极速背题**：直接展示答案与解析；按 `R` 键可开启遮挡模式做主动回忆训练。
6. **🎯 错题本高频攻坚**：按历史答错次数从高到低排序；一轮刷完若有新错题，还会贴心提示开启下一轮专练。
7. **⏱️ 全真限时模拟考**：自定题量与考试时长，交卷后输出分题型得分率，并在「统计与薄弱章节」记录成绩曲线。

## 4. 题库体检去重、薄弱章节诊断与 AI 讲题联动

- **🩺 题库体检与一键去重**：在「题库与查重体检」点击右上角 **「题库体检与去重」**，系统会扫描所有重复题干、缺失答案及选项越界问题，支持一键无损去重。
- **📊 薄弱章节排行榜**：在「统计与薄弱章节」可查看五阶段记忆分布条，以及按薄弱程度排序的章节诊断列表——点击任意章节右侧的 **「⚡ 突击此章」** 即可直接进入该章斩杀训练！
- **✨ AI 讲题助手联动**：遇到原题库没有解析的难题，在答题反馈区点击 **「✨ 一键复制 AI 讲题提问词」** 发给任意 AI 大模型，拿到讲解后再点 **「📋 粘贴剪贴板内容存为本题解析」** 即可永久保存！
- **⌘K 全局快搜**：在任何界面按 `Cmd+K`（Mac）或 `Ctrl+K`（Windows/Linux），输入关键词即可秒查题目与答案。

## 5. 多电脑/多浏览器免费云同步配置（GitHub Gist）

无需任何后端服务器或数据库，利用你自己的 GitHub 账号即可在 Mac、Windows、公司电脑与家里电脑间免费安全同步：

1. 登录 GitHub，打开 [Personal Access Tokens (Classic)](https://github.com/settings/tokens/new)。
2. Note 填 `ExamSprint Sync`，勾选权限中的 **`gist`** 一项（无需勾选其他任何权限），点击底部 **Generate token** 并复制生成的 `ghp_...` 令牌。
3. 打开极速刷题宝左侧 **「云同步与偏好」**，将 Token 粘贴进输入框，点击 **「🔄 保存并立即双向同步」**。
4. 在另一台电脑的客户端或浏览器中填入同一个 Token（Gist ID 留空即可自动识别），点击同步即可将两边的题库、错题本、斩杀记录、活跃热力图与助记笔记**无冲突双向合并**！

## 6. 一键编译生成 macOS / Windows / Linux 桌面安装包

1. 打开你的 GitHub 仓库：`https://github.com/AtomBoyC/exam-sprint-quiz`
2. 点击顶部 **Actions** → 左侧点击 **「Build Desktop Apps (macOS / Windows / Linux)」** → 右侧点击 **「Run workflow」**。
3. 等待云端编译完成后，在该任务页面底部的 **Artifacts** 区域即可直接下载三端原生安装包：
   - **macOS**：`ExamSprint-macOS-Universal`（`.dmg`，同时支持 Apple M 系列芯片与 Intel）
   - **Windows**：`ExamSprint-Windows-x64`（`.exe` / `.msi` 安装程序）
   - **Linux**：`ExamSprint-Linux-x64`（`.AppImage` / `.deb`）

> 💡 macOS 首次打开开源未公证应用如提示“无法验证开发者”，在「系统设置 → 隐私与安全性」底部点「仍要打开」，或在终端运行 `xattr -cr /Applications/ExamSprintQuiz.app` 即可。
