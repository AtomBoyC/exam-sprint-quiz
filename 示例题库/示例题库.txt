一、单选题
1. 我国的根本大法是（ A ）。
A. 宪法  B. 民法典  C. 刑法  D. 行政法
解析：宪法具有最高的法律效力。

2. 在有序数组中使用二分查找的时间复杂度为（）
A. O(1)
B. O(log n)
C. O(n)
D. O(n log n)
答案：B
解析：每次将搜索区间减半，复杂度为 O(log n)。

二、多选题
3. 以下属于常见前端核心技术的有（）
A. HTML
B. CSS
C. JavaScript
D. MySQL
答案：ABC
解析：MySQL 是后端关系型数据库。

三、判断题
4. HTTPS 是在 HTTP 与 TCP 之间加入了 SSL/TLS 加密层。（对）
解析：提供加密、认证和完整性保护。

5. 栈（Stack）是一种先进先出（FIFO）的线性结构。（×）
解析：栈是后进先出（LIFO）。

四、简答题
6. 为什么 TCP 建立连接需要三次握手而不是两次？
答案：为了防止已失效的连接请求报文段突然又传送到了服务端，从而产生错误并浪费服务端资源。
