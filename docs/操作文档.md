## 1. 启动与运行方式

本项目为 **100% 纯前端离线 Web 应用**，无任何后端服务或第三方 CDN 依赖：

- **桌面端（macOS / Windows）**：双击项目根目录的 `index.html`，使用 Chrome、Safari（16.4+）、Edge 或 Firefox 打开即可。
- **在线端（手机 / 平板 / 电脑通用）**：开启 GitHub Pages 后直接用浏览器访问在线网址，也可通过手机浏览器的「添加到主屏幕」像 App 一样打开。
- **隐私说明**：题库内容、答题记录、错题本、助记笔记全部保存在当前浏览器的 `IndexedDB` 本地数据库中，**不会经过任何服务器**。

## 2. 题库导入操作指南（全格式规范）

点击顶部导航栏 **「📤 导入题库」**，支持 **文件拖拽上传** 与 **智能文本粘贴** 两种方式。导入前均会展示识别统计与前 8 题预览，确认无误后可选择 **「确认导入为新题库」** 或 **「追加到当前题库」**。

### 2.1 Excel (`.xlsx`) / CSV / TSV 格式

- **带表头表格（推荐）**：系统会自动扫描前 6 行识别表头（即使第 1 行是大标题也会自动跳过），常见列名自动映射：
  - 题干列：`题目` / `题干` / `问题` / `question` / `stem`
  - 选项列：`选项A` ~ `选项H`（或 `A` ~ `H`），或单列合并选项 `选项`
  - 答案列：`答案` / `正确答案` / `参考答案` / `answer`
  - 解析列：`解析` / `答案解析` / `analysis` / `explanation`
  - 题型列：`题型` / `类型` / `type`（可选，省略时会自动根据选项与答案推断）
  - 章节列：`章节` / `分类` / `知识点` / `category`（可选）
- **无表头 / 含空列的表格**：即使没有表头、存在多列空白，系统也会基于列内容启发式自动推断题干、选项、答案和章节；若某列识别有偏差，可直接在预览区 **「🛠️ 表格列映射」** 下拉框中手动调整，预览实时刷新。
- **多工作表 Excel**：支持在预览区下拉切换不同的 Sheet 分别导入或追加。
- **编码兼容**：CSV 文件自动检测 UTF-8（含/不含 BOM）以及 Windows/Excel 默认的 **GBK / GB18030**，不会出现中文乱码。
- **旧版 `.xls` 提示**：如遇 97-2003 旧版 `.xls` 文件，请用 Excel / WPS / Numbers 另存为 `.xlsx` 或 `.csv` 后再上传。

### 2.2 Word (`.docx`) 格式

- 同时支持 **Word 表格题库** 和 **Word 段落题库**，并内置自动编号恢复（解析 `word/numbering.xml`）。
- 旧版 `.doc` 文件请先在 Word / WPS 中另存为 `.docx` 后上传。

### 2.3 TXT / Markdown / 智能文本粘贴（PDF 题库推荐用法）

如手头是 **PDF 题库** 或网页/微信聊天中的题目，直接 **全选复制文字（`Cmd+A` / `Ctrl+A` → `Cmd+C` / `Ctrl+C`）** 粘贴到右侧文本框即可，支持以下常见排版：

#### 排版 A：标准分行 + 章节标题 + 解析
```text
一、单选题
1. HTTP 协议默认使用的端口号是？
A. 21
B. 22
C. 80
D. 443
答案：C
解析：HTTP 默认端口 80，HTTPS 默认端口 443。
```

#### 排版 B：题干括号内嵌答案 + 行内选项（自动挖空防剧透）
```text
1. 我国的根本大法是（ A ）。
A. 宪法  B. 民法典  C. 刑法  D. 行政法

2. 队列是一种后进先出的数据结构。（ × ）
```

#### 排版 C：文末附带「参考答案汇总」
```text
1. 太阳从哪边升起？
A. 东  B. 西  C. 南  D. 北

2. 以下哪些是质数？
A. 2  B. 3  C. 4  D. 5

参考答案：
1.A 2.ABD
```
> 也支持区间格式，如 `1-5: ABCDA`。

#### 排版 D：直接粘贴 CSV / Excel 单元格
直接从 CSV 文件或 Excel 复制多行多列粘贴到文本框，系统会自动识别为表格并进入可视化列映射预览。

### 2.4 JSON 格式

支持数组 `[...]` 或 `{ "questions": [...] }` / `{ "data": [...] }` 结构，字段同时兼容中英文键名（如 `stem/question/题目`、`options/A~D/选项`、`answer/答案`、`analysis/解析`、`category/章节`、`type/题型`）。

```json
{
  "questions": [
    {
      "type": "single",
      "category": "第一章 网络基础",
      "stem": "HTTPS 默认端口号是？",
      "options": ["21", "22", "80", "443"],
      "answer": "D",
      "analysis": "HTTPS 使用 443 端口。"
    }
  ]
}
```

> 可在「导入题库」页面点击 **⬇️ CSV/Excel 模板 / TXT 模板 / JSON 模板** 一键下载标准模板。

## 3. 6 大刷题模式与高效备考流程

在首页顶部可按 **题型**、**章节分类** 缩小刷题范围，并勾选 **「选项乱序」** 与 **「答对自动下一题」** 开关。

| 模式 | 适用阶段 | 核心机制 |
|---|---|---|
| **📖 顺序刷题** | 第一遍系统学习 | 按原题序逐题作答，即时反馈解析，支持自动保存断点续刷 |
| **🔀 随机乱序刷题** | 强化巩固 | 打乱题序，配合「选项乱序」避免形成位置记忆 |
| **⚔️ 斩杀冲刺模式** | 考前快速扫盲 | 仅出尚未掌握的题；连对达标（默认 1 次，可在设置调整为 2/3 次）自动标记「已斩杀」，实时显示剩余待斩数量 |
| **⚡ 极速背题模式** | 临考前速览 | 直接高亮答案与解析；点击「遮挡答案」或按 `R` 可切换为主动回忆闪卡模式 |
| **🎯 错题本攻坚** | 消灭薄弱点 | 所有错题自动收录并按历史错误次数从高到低排序；可在设置中开启「答对自动移出错题本」 |
| **⏱️ 全真模拟考试** | 考前自测热身 | 自定义题量与倒计时，答题期间不剧透答案，交卷后自动评分、输出分题型正确率并支持「只复盘错题」 |

### 推荐考前突击节奏
1. **第一轮扫盲**：开启 **⚔️ 斩杀冲刺模式** + **答对自动下一题**，快速过一遍全库，筛选出真正不会的题。
2. **第二轮攻坚**：勾选 **选项乱序**，进入 **🎯 错题本攻坚**，逐个消灭高频错题，难记的题按 `S` 收藏并写下 **📝 助记笔记**。
3. **第三轮热身**：进入 **⏱️ 全真模拟考试** 限时测验，再点击 **🖨️ 导出错题速记打印单**，用浏览器打印或另存为 PDF 考前速览。

## 4. 题库管理、在线修改与数据备份

点击顶部 **「📚 题库管理」** 可进行以下操作：

- **多题库管理**：自由切换、重命名、清空某题库的刷题进度（保留题目）或删除题库。
- **全文检索与状态筛选**：按关键词搜索题干/选项/解析/笔记，或按「错题本 / 待斩杀 / 已掌握 / 已收藏 / 未做过 / 缺少答案」快速筛选。
- **在线编辑与新增**：刷题界面或管理界面均可点击 **「✏️ 编辑」** 随时修正错字、补充解析，也可点击 **「➕ 手动新增题目」** 录题。
- **导出 JSON 备份**：将整个题库导出为标准 `.json` 文件，方便换电脑/换手机导入。
- **导出错题速记打印单**：生成排版精美的离线 `.html` 文件，双击打开后点击「打印 / 存为 PDF」即可获得按错题频次排序的考前速记单（包含你的个人助记笔记）。

## 5. 快捷键与移动端手势

### 桌面端全键盘操作
- `1`–`6` 或 `A`–`F`：选择选项（判断题按 `1` 选正确、`2` 选错误）
- `Enter` / `Space`：提交多选/填空、揭晓简答题参考答案，或切换下一题
- `←` / `→`：上一题 / 下一题
- `S`：收藏 / 取消收藏
- `K`：手动标记 / 取消已斩杀
- `R`：背题模式下切换遮挡/显示答案
- `D`：随时切换浅色 / 深夜护眼暗色模式
- `Esc`：关闭弹窗或答题卡

### 移动端手势
- **左右滑动题目卡片**：快速切换上一题 / 下一题
- **点击顶部「📋 答题卡」**：滑出全题号网格快速跳题

## 6. 私有题库本地预置（高级）

如果你希望本机打开 `index.html` 时自动预载入一套个人私有题库，但又**不想把它提交到公开 GitHub 仓库**，可利用本仓库已配置好 `.gitignore` 忽略规则的 `js/builtin-bank.js`：

1. 在本地新建 `js/builtin-bank.js`（已在 `.gitignore` 中被忽略，不会被 `git push` 上传）：
   ```js
   window.BUILTIN_EXAM_BANK = {
     id: 'my_local_bank_01',
     name: '我的本地预置题库',
     createdAt: Date.now(),
     questions: [ /* 从题库管理导出 JSON 中的 questions 数组 */ ]
   };
   ```
2. 刷新 `index.html`，首次打开时将自动加载该题库。

## 7. GitHub 托管与 GitHub Pages 部署教程

### 7.1 将本地修改同步到 GitHub
```bash
# 查看当前文件变更（确认私有题库已被 .gitignore 忽略）
git status

# 提交并推送更新
git add .
git commit -m "feat: 更新说明"
git push origin main
```

### 7.2 开启 GitHub Pages（手机直接在线打开）
1. 进入你的 GitHub 仓库页面，点击顶部 **Settings** → 左侧 **Pages**。
2. 在 **Source** 选择 **Deploy from a branch**。
3. 在 **Branch** 选择 `main`，目录保持 `/ (root)`，点击 **Save**。
4. 等待 1～2 分钟刷新页面，即可看到在线访问链接：
   `https://AtomBoyC.github.io/exam-sprint-quiz/`（或你 Fork 后的 `https://<你的用户名>.github.io/<仓库名>/`）

## 8. 常见问题排查（FAQ）

**Q1：刷题记录会丢失吗？换浏览器能同步吗？**  
A：所有题库和记录都保存在当前浏览器的 `IndexedDB` 中，关闭标签页、重启电脑都不会丢失；但如果清空浏览器站点数据或更换设备/浏览器，本地数据不会自动同步。建议在「题库管理」中点击 **「💾 导出 JSON 备份」** 妥善保存。

**Q2：上传 `.xlsx` 或 `.docx` 提示浏览器不支持解压？**  
A：离线解析依赖浏览器原生 `DecompressionStream` API，请使用较新版 Chrome（80+）、Edge（80+）、Safari（16.4+）或 Firefox（113+），或将 Excel 另存为 `.csv` 后上传。

**Q3：Excel / CSV 导入后选项或答案错位怎么办？**  
A：无需修改原文件！在导入预览区的 **「🛠️ 表格列映射」** 中，直接用下拉框把「题干列 / 选项A~D / 答案列 / 章节列」指到对应列，预览结果会实时刷新，确认无误再点导入即可。

**Q4：PDF 题库怎么导入效果最好？**  
A：打开 PDF → 全选复制文字 → 粘贴到「导入题库」右侧的 **「智能文本粘贴」** 框中点击「智能识别题目」。如个别题目因 PDF 换行错乱识别异常，导入后在刷题页或题库管理中点「✏️ 编辑」即可 2 秒修正。
